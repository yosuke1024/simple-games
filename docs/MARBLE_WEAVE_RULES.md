# Marble Weave (No. 72)

## ルール

玉を選び、空マスへ動かす。経路は上下左右の空マスだけを通る。斜め移動や飛び越しは不可。
同じ色を縦・横・斜めに必要数以上並べると、その列が消える。交差は重複せず全て消す。
Easyは7×7・4色・4個、Normalは9×9・6色・5個、Hardは9×9・7色・5個。
消せなかった手では予告された3個を空マスへ同時追加し、その後できた列も消す。
消せた手では追加しない。空きが3未満なら空き分だけ追加する。埋まった盤は終了。
初期は5個。色ごとに固有記号を重ねる。次の3色の予告、選択玉の到達可能マスを表示する。
消した玉1個10点、規定数を超える1個につきさらに5点。複数列の一斉消去は合計数で採点。
待ったは乱数・予告・追加・消去を含め1手全部を戻す。終了後は戻さない。
選択と経路表示が助けで、答えのHintは置かない。記録は終了時の最高得点。
保存キー: mw.saveGame / mw.stats / mw.flags / mw.prefs。最大4096手、到達時は現在得点で終了。
