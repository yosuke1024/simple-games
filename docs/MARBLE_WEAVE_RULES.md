オーナーの「つまらなすぎるので、入れません。削除して、導入を見送りましょう」という判断により、Web先行公開から取り下げる。`channel: in-development` とし、全プラットフォームの一覧・検索・お気に入り・再開・直接URL・ゲーム起動から除外する。正式収録や再公開の予定はない。保存の所有情報と検証器はバックアップ・ローカルデータ削除のため保持する。以下は取り下げ時点の実装記録。

## ルール

2026-11-03、オーナーの「戦略性を感じない」という指摘と「短い詰めパズルへ変更：決められた手数で全消し」の選択により、新規ゲームは固定の全消し問題にする。
玉を選び、空マスへ動かす。経路は上下左右の空マスだけを通る。斜め移動や飛び越しは不可。
同じ色を縦・横・斜めに必要数以上並べると、その列が消える。交差は重複せず全て消す。
EasyとNormalは5×5・3個で消去、Hardは6×6・4個で消去。
各難易度4問、合計12問。Easyは2手、Normalは4手、Hardは5手以内に全消しを狙う。
問題の玉は最初から全て見え、追加の玉や乱数による変化はない。
NormalとHardには列を消さない準備手が必要な解を用意し、消す順序を考える。
色ごとの記号と到達可能マスを表示し、色だけに依存しない。
全消し時にクリア。手数を使い切っても終了モーダルにはせず、保存・待った・再挑戦を可能にする。
待ったは移動と消去を含め1手全部を戻す。クリア後は戻さない。
答えのHintは置かない。問題ごとの最少手数を記録し、クリア後は同じ難易度の次の問題へ進める。
全問題を最初から選択でき、解放条件・連続記録・達成数による誘導は置かない。

## 保存と旧ルールの互換

保存キー: mw.saveGame / mw.stats / mw.flags / mw.prefs。
ゲーム保存と統計はv2、flagsとprefsはv1。v2は固定puzzleIdと合法手列で再構成する。
既存v1の途中ゲームは専用legacyエンジンでそのまま再開・再挑戦できる。
旧ルールはEasyが7×7・4色・4個、Normalが9×9・6色・5個、Hardが9×9・7色・5個。
初期5個、消せない手で予告3個を追加し、埋まるか4096手で終了する従来仕様を維持する。
旧得点は1個10点と規定超過1個5点のまま、新しい最少手数へ変換しない。
旧保存からv2へ移す際はrulesVersion:1 / puzzleId:nullを付け、UIで「旧ルール・スコア式」と明示する。
旧最高得点の統計は別枠で残す。v2問題の識別子や初期配置を変更しない。

## 共通契約

2026-11-03、製品オーナーの追加3本とWeb公開の依頼、および候補3本への承認による。
当初はWeb先行公開のみ。現在は上記のとおり取り下げ済みで、正式収録・Club House・Nearbyには加えない。

GameHomeHeader / GameArtwork / WebBetaNotice / BannerSlot / ResultAdSlot / ShareActionを使う。

再挑戦前の置換は既存の確認を使う。進行と統計は端末内のみ、課金・通信・時間制限は無い。
英語が原文、jaを含む13言語はAI作成。人による翻訳レビューは未実施。
