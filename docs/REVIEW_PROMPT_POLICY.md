# Simple Games — ストアレビュー導線ポリシー

「静かに、正直に」([BRAND.md](BRAND.md))はレビューのお願いにも適用される。
評価を乞うアプリにしない。実装は `src/services/review.ts` と
`src/ui/components/ReviewPrompt.tsx`(表示判定は shell の `App.tsx`)。

## 流れ

1. アプリ内で静かに 1 問だけ聞く:「Simple Games を楽しめていますか?」
2. **楽しい** → ネイティブの In-App Review カード(Google Play が表示可否を判断)。
   カードが出せない環境ではストア掲載ページを開くだけ。
3. **いまいち** → ストアには誘導しない。フィードバックのメールドラフトを開く
   (宛先は `@simple-games/brand` の `SUPPORT_EMAIL`)。
   **送信するのはユーザー自身**。アプリは何も送信しない。
   ドラフト末尾に付くのはバージョンと言語のみで、ユーザーが消せる。
4. **あとで** → 何もしない。

「いまいち」をストアレビューから遠ざけるのは評価操作ではなく導線の設計:
不満は開発者に届く方が直せる。どちらを選んでも機能差・報酬は一切ない。

## 頻度の規律(ナグしない)

- **エンゲージメント先行**: 合計 5 勝(全ゲーム横断、デイリー含む)まで何も聞かない。
- **タイミング**: ゲームからコレクション画面へ戻った瞬間のみ。
  起動直後・プレイ中・結果画面には出さない。
- **回数**: 1 インストールにつき**最大 2 回**。
  「あとで」は 20 勝後に一度だけ再度聞く。
  回答した(どちらの方向でも)ら**二度と聞かない**。
- **オフライン時は聞かない**(「楽しい」を選んでも何も開けないため)。
- 表示した瞬間に回数を記録する(強制終了でカウントが巻き戻らない)。

## 禁止事項

- 星の数を先に聞く「事前スクリーニング」UI(星型ウィジェット等)は作らない。
  質問は「楽しめているか」であって「何点つけるか」ではない。
- レビューと引き換えの報酬・機能解放。
- 否定的な回答への再質問・引き止め。
- ストアレビュー API の呼び出しをこの導線以外に置かない。

## 保存

`sg.review`(`storage/schemas.ts` の `reviewSchema`)に勝利数・表示回数・
回答済みフラグのみ。日時・端末情報は保存しない。
「ローカルデータを削除」で他のレコードと同様に消える(= 質問も復活する)。
