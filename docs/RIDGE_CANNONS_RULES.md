# Ridge Cannons

## ルール

山を隔てた2門が交互に1発ずつ撃つ、オリジナルの砲撃対戦。プレイヤーが左、CPUが右。
照準角10〜80度、威力20〜100。スライダーと±ボタンで調整し「発射」で確定。
角度は各砲から相手側を向いた仰角。風は各ラウンド一定で左右両者に同じ力を与える。
地形はシードで生成され固定。地形破壊・移動・装備はない。飛行は固定ステップの放物運動。
着弾距離で最大40ダメージ、直撃ほど大きい。自分に近い着弾も同じ規則で被弾する。
両者100耐久。0になれば終了。同時0は引き分け。12ラウンド後は残耐久で勝敗、同じなら引き分け。
前弾の軌道と着弾は残す。予告は砲口の短い方向線のみで、正解の軌道は表示しない。
CPUは公開地形・風だけを使い、固定上限の候補を比較する。難度は狙いの誤差だけを変える。
CPU発射は可視かつ対局中だけ1回予約、非表示/モーダル/離脱で取り消し、復帰で再予約する。
発射後は実際の計算済み軌道に沿って砲弾を1.1秒で飛ばし、その後に着弾・耐久・結果を表示する。
高い弾道も画面内に収まるよう表示範囲を合わせる。飛行中は次の発射とCPU手番を止める。
保存は入力直後に確定し、演出の終了に依存しない。非表示・ダイアログ・退出では演出を終了し、
再開時に再生しない。Reduced Motionは即時結果。無操作中は描画ループを持たない。
待ったは無し。撃つ前は自由に調整でき、前弾の軌道が助けになる。

## UIと保存

360×640、319px幅、タブレットで盤面・主操作を確認する。ライト/ダーク、キーボード、
タッチ相当の操作、フォーカス、Reduced Motion、ダイアログ中の入力停止を確認する。
未実施の実機検証を済みとは書かない。Quick Rulesは図つき3ステップ。
設定はEasy/Normal/Hard、再開、統計を提供。保存は`rc.game/prefs/stats/flags`の4キー。
入力履歴をシードから再生し、不正値・不正手・過長履歴・終了後入力を拒否する。
保存のv1はベータ中。ゲーム変更・戻る・非表示・アンマウントで同期し、終了時は進行保存を消す。
同じ局の再挑戦と新しい局を区別し、進行中の置き換えは確認する。
