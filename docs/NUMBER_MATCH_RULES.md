# Number Match — 正式ゲームルール

このドキュメントが Number Match のルールの唯一の情報源である。
実装 (`apps/number-match/src/game/`)、チュートリアル、Hint、単体テストは
すべてこのルールに従う。ルールの例外を UI 側へ個別実装してはならない。

## 1. 盤面

- 盤面は **9列** のグリッド。数字は読み順(左→右、上→下)で詰めて並ぶ。
- 最終行は 9 個未満の場合がある(部分行)。
- 内部表現は読み順のフラットな配列。定数:
  - `COLS = 9`
  - `INITIAL_CELLS = 27`(初期盤面は 3 行)
  - `MAX_CELLS = 270`(30 行相当。盤面の最大サイズ)
- 各セルは数字 `1`〜`9` を持ち、状態は **live**(未消去)または **cleared**(消去済み)。
- 消去済みセルは空きマスとして盤面に残り、見た目で明確に区別する。

## 2. ペアの条件(値)

2 つの live セルは、以下のいずれかを満たすとき「値として一致」する。

- 同じ数字である(例: `3 + 3`、`7 + 7`)
- 合計が 10 になる(例: `1 + 9`、`2 + 8`、`3 + 7`、`4 + 6`、`5 + 5`)

## 3. ペアの条件(接続)

値が一致する 2 セルは、さらに以下のいずれかの位置関係にあるとき消去できる。
いずれも「2 セルの間にあるすべてのセルが消去済み」であることが条件
(間にセルがない=隣接も含む)。

1. **読み順**: フラット配列上で間のセルがすべて消去済み。
   同一行内の横方向、および **行末→次の行頭** をまたぐ接続はこの規則に含まれる。
2. **縦方向**: 同じ列で、間の行の同列セルがすべて消去済み。
3. **斜め方向**: 行差と列差の絶対値が等しい対角線上で、間の対角セルがすべて消去済み。

間に live セルが 1 つでもあれば接続できない。

## 4. 消去と行の除去

- 有効なペアを選択すると、2 セルは消去済みになる。
- 消去の結果、**完全な行(9 セル)が全て消去済み** になった場合、その行は盤面から取り除かれ、
  下の行が詰まる。複数行が同時に全消去になった場合はすべて取り除く。
- 盤面末尾に連続する消去済みセルは取り除く(末尾の部分行が全消去になった場合を含む)。
- 行の除去はプレイヤーに有利に働く(行が詰まることで新しい縦・斜めの接続が生まれる)。

## 5. Add Numbers

- 消去可能なペアが見つからないとき(いつでも実行自体は可能)、
  **残っている live の数字を読み順のまま盤面末尾へ追加**できる。
- 消去済みセルは追加しない。順序は維持する。
- 追加後の盤面サイズが `MAX_CELLS` を超える場合、Add Numbers は実行できない。
- 利用回数の制限はない。広告視聴・課金は不要。オフラインで利用可能。

## 6. クリア条件

盤面上のすべての数字が消去された(live セルが 0 になった)場合、ゲームクリア。

## 7. ゲームオーバー条件

以下がすべて成立した場合、ゲームオーバー。

- 盤面に live の数字が残っている
- 消去可能なペアが存在しない
- Add Numbers を実行できない(追加すると `MAX_CELLS` を超える)

ゲームオーバー後は「同じ問題を再挑戦(同じ Seed)」「新しいゲーム」「ホームへ戻る」を選べる。
広告視聴による Continue は存在しない。

## 8. Undo

- 消去・Add Numbers の各操作の直前の盤面スナップショットを履歴に積む。
- Undo は履歴を 1 つ戻す。ゲーム開始時点まで戻せる。
- 広告視聴・課金は不要。回数制限なし(内部上限 2000 は通常プレイで到達不能)。
- アプリ再起動後の Undo 履歴復元は必須ではない(現在の盤面は復元する)。

## 9. Hint

- 決定的な走査(インデックスの小さい順)で、実際に消去可能なペアを 1 組だけ提示する。
- 自動では消去しない。
- ペアが存在しない場合は Add Numbers を案内する。
- 広告視聴・課金は不要。回数制限なし。

## 10. 盤面生成と Seed

- 乱数は `xmur3`(文字列ハッシュ)+ `mulberry32` による決定的 PRNG。
  同じ Seed 文字列からは常に同じ盤面が生成される。
- 初期盤面は `INITIAL_CELLS` 個のセルに `1`〜`9` を一様に割り当てる。
  消去可能なペアが 1 組も存在しない場合は、同じ PRNG 列を消費して決定的に再生成する。
- **Classic**: 新規ゲームごとにランダムな Seed を生成。Restart は同じ Seed を再利用。
- **Daily Challenge**: 端末のローカル日付から `daily-YYYY-MM-DD` 形式の Seed を作る。
  同じ日付では同じ盤面。サーバー時刻は使用しない。日付変更の不正対策は行わない。
