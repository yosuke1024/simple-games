# Simple Games — 広告ポリシー

## 基本方針

- 広告はオンライン利用時の収益化に使用する。
- **広告はゲーム機能の解放条件にしない。** Hint / Undo / Add Numbers / Continue を
  広告視聴の対価にしない。
- オフライン時には広告が表示されないが、全機能を引き続き利用できる。
- 広告取得を待たせるローディングを作らない。

## 使用する広告(初期リリース)

- Anchored Adaptive Banner(ゲーム画面下部)
- Interstitial(自然な区切りのみ)

使用しない: Rewarded / Rewarded Interstitial / App Open / Native 広告。
Rewarded は「広告報酬」と「全機能オフライン」のブランドメッセージを複雑にするため
初期版では実装しない。

## バナー広告

- ゲーム盤・操作ボタンに重ねない。広告と操作領域の間に余白を設ける。Safe Area を考慮。
- **レイアウトシフト防止方式**: 「広告領域を常に確保する」方式を採用する。
  ネイティブ環境でバナーが有効な場合、画面下部に固定高のスロットを画面表示時から確保し、
  以後この高さを縮めない(実広告の高さがスロットを超える場合のみ拡大を許す)。
  広告が取得できない間・オフライン時は静かな空き領域のままにする。
  比較検討: 「表示前にレイアウト確定」案はロード完了時点で盤面が動くため不採用。
- 広告が取得できなくてもゲームを継続する。
- 開発環境では Google 公式のテスト広告 ID のみ使用する。
  本番広告 ID はコードへ直接埋め込まず、ビルド時に環境変数で注入する。
  本番ビルドで ID が未設定の場合、広告は表示しない(ゲームは通常動作)。

## インタースティシャル広告

表示可能地点(これ以外では表示しない):

- ゲームクリア後 / ゲームオーバー後 / New Game を選択した後 /
  十分なプレイ時間を経たセッション終了時

表示禁止地点:

- アプリ起動直後 / アプリ復帰直後 / チュートリアル中 / ゲーム開始直後 /
  ゲームプレイ途中 / 数字選択中 / Undo・Hint・Add Numbers 実行時 /
  設定画面から戻った直後 / 広告ロード完了直後の予期しないタイミング

頻度制御の初期値(Remote Config で上書き可能、アプリ内デフォルトが常に存在):

```text
interstitial_enabled = true
interstitial_first_session_disabled = true
interstitial_min_play_minutes = 10
interstitial_min_completed_games = 2
interstitial_min_interval_minutes = 15
interstitial_daily_limit = 3
```

要件:

- ロード済みの場合のみ表示。未ロードなら即座にスキップし、本来の画面へ遷移する。
- 表示失敗時は本来の画面へ即座に遷移する。
- 同じ広告インスタンスを再表示しない。表示後に次の広告をバックグラウンドで準備する。
- 日次上限・最小表示間隔は端末内で管理する。
- Remote Config(`interstitial_enabled = false`)で即時停止できる。

## ストア表現

広告が存在するため、"Ad-free" / "No ads" 等の表現を使用しない(BRAND.md 参照)。
