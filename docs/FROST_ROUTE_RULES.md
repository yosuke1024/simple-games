# Frost Route

## ルール

氷の上を壁まで滑り、3個の結晶を通過して集め、出口のマスに止まる経路パズル。
Easyは7×7、Normalは8×8、Hardは9×9。移動は上下左右、壁/盤外の直前で停止。
結晶は通過で回収。出口は停止した時だけ判定し、未回収があると終わらない。
盤面はシード生成。BFSで位置×回収マスクを探索して解ける盤だけ採用する。
候補80回まで、状態数は最大81×8。決定的な検証済みのフォールバックを用意し無限生成しない。
最短手数は計算値として表示し、速さは競わない。盤上の行き先ボタン、矢印キー/WASD、方向ボタン。
Undoは位置と回収状態を戻す。ヒントは現在位置から最短解の最初の方向だけを強調。
詰んだときはその旨を示しUndo/同じ盤面の再挑戦を使う。最短を自動実行しない。
結果には手数・最短手数。リトライと新しい盤面はどちらも無料・無制限。

## UIと保存

360×640、319px幅、タブレットで盤面・主操作を確認する。ライト/ダーク、キーボード、
タッチ相当の操作、フォーカス、Reduced Motion、ダイアログ中の入力停止を確認する。
未実施の実機検証を済みとは書かない。Quick Rulesは図つき3ステップ。
設定はEasy/Normal/Hard、再開、統計を提供。保存は`fr.game/prefs/stats/flags`の4キー。
入力履歴をシードから再生し、不正値・不正手・過長履歴・終了後入力を拒否する。
保存のv1はベータ中。ゲーム変更・戻る・非表示・アンマウントで同期し、終了時は進行保存を消す。
同じ局の再挑戦と新しい局を区別し、進行中の置き換えは確認する。
