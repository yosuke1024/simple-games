# Falling Blocks — ゲームルール

この文書が `apps/simple-games/src/games/falling-blocks/` の仕様の正本。
ゲーム ID は `falling-blocks`、i18n 接頭辞は `fallingBlocks`、保存接頭辞は `fb.`。
Web 先行公開として追加し、正式収録・Club House 対応は行わない。
ブランド原則は [PRODUCT_PRINCIPLES.md](PRODUCT_PRINCIPLES.md) が上位にある。

## 1. 盤面と目的

10 列 × 18 行の盤面へ、4 マスでできた 7 種類のピース(I / O / T / S / Z / J / L)が落ちる。
左右移動と回転で水平の行を埋める。埋まった行は同時に消え、その上のブロックが下がる。
新しいピースの登場位置が塞がっていれば終了。勝利条件はなく、点数を記録する。
静的な 8×8 の Block Puzzle とは独立したゲームである。

## 2. ピースと回転

7 種類を 1 個ずつ含む袋をシャッフルして配る。袋はシードと袋番号から決定的に決まり、
盤面に合わせてピースを変更しない。同じシードへの再挑戦は同じ順番になる。
次の 1 個と、現在のピースの着地点を輪郭で表示する。

回転は時計回り。O は形が変わらない。各ピースの固定された 2×2 / 3×3 / 4×4 の
枠内で回転し、その場所、左 1、右 1、左 2、右 2 マスの順に可能な場所を選ぶ。
上方向への補正や、他のブロックを通り抜ける回転はない。
落下を試みた場所が塞がっていれば現在位置で固定し、行を消して次のピースを出す。

## 3. 操作

画面には左・回転・右・下・落下の 5 ボタンを常設する。左・右・下は押し続けると
260 ms 後から 100 ms ごとに繰り返す。回転と落下は 1 回の押下で 1 回。
下は 1 マス下げるソフトドロップ、落下は輪郭の位置まで即座に落とし固定するハードドロップ。

キーボードは ← / → で左右、↑ で回転、↓ で下、Space でハードドロップ、P で
開始・一時停止・再開。左右と下はキーリピート可、回転と落下はリピートしない。
フォーカスしたボタン上の Space はそのボタンだけを操作する。
キー・タッチは同じ Pure TypeScript の関数へ渡す。

新しい盤面は Ready で静止する。「Start Playing」で開始する。途中で止めた盤面は
「Resume」で明示的に再開する。操作が開始・再開を暗黙に起こすことはない。
再挑戦は何度でも無料。同じ順番と新しい順番の両方を結果カードとヘッダーの再開確認に出す。
Undo / Hint / 復活は作らない。着地点と次のピースは常に見えている。

## 4. 速度と点数

レベルは `min(20, 1 + floor(lines / 10))`。自然落下は
`max(120, 850 - (level - 1) × 45)` ms ごとに 1 マス進む。
移動・回転で自然落下のタイマーを張り直さない。

1 / 2 / 3 / 4 行の同時消去は 100 / 300 / 500 / 800 点に、消去前のレベルを掛ける。
ソフトドロップは実際に下げた 1 マスにつき 1 点、ハードドロップは 1 マスにつき 2 点。
自然落下、回転、左右移動には点を付けない。連鎖倍率・デイリー・ストリークはない。

## 5. 中断・時間・保存

自然落下はゲーム画面で Running のときだけ 1 本の連鎖タイマーを持つ。
一時停止、再挑戦ダイアログ、ホーム、hidden、window blur、native pause、終局、
アンマウントで止める。復帰・フォーカス回復だけでは再開しない。
タイマー、キー、押し続け、visibility / blur / native リスナーは終了時にすべて解放する。
ダイアログと結果表示の間は盤面を inert にし、ゲームキーを登録しない。

保存はピースの固定、一時停止、退出、バックグラウンド、アンマウントで行う。
自然落下の各 tick では書かない。Ready の新盤面も保存する。戻した実行中の局は必ず Paused。
経過時間は `performance.now()` の差で、Running の間だけ計算する。時計の表示はない。
秒は保存に書く前に統計へ計上し、再開時は保存の秒を `elapsedRef` / `bookedRef` 両方へ積む。
消した行数も保存時点まで統計へ計上してあり、復帰時は同じ行数から差分だけを計上する。

保存キーは次の 3 つだけ。

| キー          | 内容                                                                                            |
| ------------- | ----------------------------------------------------------------------------------------------- |
| `fb.saveGame` | schemaVersion 1、seed、board、active、pieceIndex、score、lines、status、elapsedSeconds、savedAt |
| `fb.stats`    | schemaVersion 1、played、bestScore、linesCleared、totalPlaySeconds                              |
| `fb.flags`    | schemaVersion 1、tutorialCompleted                                                              |

`played` は Ready → Running の 1 回だけ増える。自己ベストと累計行数は途中退出でも残す。
終了時には保存スロットを削除する。壊れた JSON・範囲外の値・重なるピース・配りと異なる種類・
ピース数と消去行数に合わない占有マス数・未消去の満杯行は拒否し、ゲーム全体を止めない。
保存領域の故障はほかのゲームへ伝播しない。Quick Rules のフラグだけ欠けても保存局を上書きしない。

## 6. 画面・アクセシビリティ

共有のホームヘッダー、Web ベータ告知、3 ステップの Quick Rules、統計、結果広告枠を使う。
Quick Rules は移動と回転、ラインと着地点、終了と一時停止の順。未公開の外部ガイドはリンクしない。
結果の共有は `outcome="played"` で、その局の点数・消去行数だけを渡す。自己ベストは送らない。
4 行以上消した局の終了だけが既存のレビュー完了カウンターに寄与する。

盤面は SVG。固定済みマスは横線入り、操作中は塗り、着地点は破線の輪郭で区別する。
色だけで状態を伝えない。読み上げ用にピース種類と位置を付け、行数と動作状態の変更を通知する。
コントロールは 44 px 以上のタップ標的を持ち、長い翻訳は折り返す。盤面は左右反転しない。
独自のフラッシュ・粒子・画面揺れ・常時 RAF はない。Reduced Motion の結果表示は共有の設定に従う。
音は既存の設定付き `select` / `clear` / `gameOver` を固定・消去・終局で使う。

作者・ネイティブのレビュー、独立逆翻訳、別モデル監査は未実施。高リスクキーは追加しない。
