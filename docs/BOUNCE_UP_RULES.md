## これまでに決まったこと(製品オーナーの判断、2026-10-19)

詳細と理由は計画書の「50. Bounce Up」にある。

- 足場に乗るたびに自動で跳ね、左右に動いて登っていく、縦長 1 画面のアーケード。論理盤面は 360×640。
  左右の端は反対の端へつながる。足場を逃して画面の下まで落ちたら終わり。スコアは到達した最大の高さ。
- モードは Endless だけで、デイリーは無い。設定は足場の幅 Normal / Wide(1.5 倍)の 1 つだけで、記録は
  幅ごとに分ける。
- 状態は `ready` / `running` / `paused` / `over`。バックグラウンドと Back で止まり、復帰してもタップまで
  再開しない(Back の正確な扱いは Phase 2 で決める)。
- 操作は 3 つ。相対ドラッグ(指の移動量を 1:1 で目標の位置へ写し、体は最高速で追う。遅れには上限を置く)、
  ← → / A D、タッチ端末では盤に重ねた ◀ ▶。
- Undo と Hint は作らない。助けは即時リトライと Wide。コンティニュー・復活・パワーアップ・ジェットパックは
  作らない。はねる足場は v1 では作らない。
- 保存キーは `bo.stats`(played・幅ごとの最高・累計・総プレイ秒)/ `bo.flags` / `bo.prefs`。ランの途中保存は
  作らない(Bunny Hop §10 と同じ)。途中で離れたランの到達高も統計に入れる。
- 物理は固定ステップ 1/120 秒で、持ち越しに上限を置く。重力 1800 px/s²・初速 760 px/s・最高水平速度
  600 px/s は初期値で、実機で決める。
- 足場 i は (seed, i) だけで決まる。各段に固体の安全鎖を 1 枚置き、動く足場と消える足場は鎖の外にだけ
  置く。不変条件(段差 ≤ 頂点の高さの 82%、鎖の水平距離 ≤ 上限)は性質テストで確かめる。自動操縦
  (最高速の 3/4)で 200 seed × 2000 段を踏破できることもテストで確かめる。**提案時の使い捨て試作で
  出た値(踏破を含む)は、実装で再現するまで検証済みと書かない。**
- 足場の種類は、色だけでなく形でも見分けられるようにする。足場を雲に見せる見た目は残してよい。
- このジャンルの代表作に固有の表現(方眼の罫線・四本足の主人公・足場の絵・効果音)は複製しない。
  製品名はアプリにもストア文言にも書かず、この文書の比較の節でだけ書く
  ([BRAND.md](BRAND.md)「自社タイトルと比較対象の名前」)。
- Quick Rules の文案(仮。3 ステップ)
  1. 指を左右にすべらせて動かす。ジャンプは足場に乗るたびに自動で起こる。
  2. 画面の端から出ると、反対の端から入ってくる。上の足場へ登っていく。
  3. 足場を逃して下まで落ちたら終わり。登った高さが記録になる。

## i18n

- `en` が原文になる。**訳はまだ無い** — 今はスキャフォールドの段階で、14 言語とも英語の仮文である。
  `ja` と他 12 言語は AI が書く予定で、書いた後も作者とネイティブが読むまでは未読として扱う
  ([I18N_POLICY.md](I18N_POLICY.md))。高リスク文言(無料・オフライン・課金・削除・保存の約束)はこのゲームの文言に足さない。
