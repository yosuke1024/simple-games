本文はまだ無い。**本文 — 盤と物理・レースと着順・操作・衝突・交通の生成・ライバルとペース・
レベル・助け・保存と統計・中断・Quick Rules・画面と寸法・演出とアクセシビリティ・i18n・
意図的な差分(§13)・比較対象との対応(§14)・Club House(§15 以降)・検証の範囲・実測 — は Phase 2 で、

実機 2 台の Phase 0(入力マッパーとスロットル表示だけの空コース)を通してから書く** — 通るまで
2 軸 1 本指の操作は凍結しない。以後は実装・テスト・Quick Rules がこの文書に従い、コードはここへ
`§n` で言及する。挙動を変えるときは、同じコミットでこの文書を直す。それまでは計画
[plans/2026-10-20-overtake-make-the-target-nested-tic-tac-toe-scopa-tangram.md](plans/2026-10-20-overtake-make-the-target-nested-tic-tac-toe-scopa-tangram.md)

ブランド原則([PRODUCT_PRINCIPLES.md](PRODUCT_PRINCIPLES.md))はこの文書より上位にある。

ゲーム ID は `overtake`、i18n キーの接頭辞は `overtake`、保存キーの接頭辞は `ot.`、カテゴリは

## これまでに決まったこと(2026-10-20 — オーナーが 5 本をまとめて採った提案の仕様と、計画の判断。詳細は計画)

計画の「52. Overtake」に理由と、提案時の算術・試作の値(検証済みではない)がある。

- 縦に流れる道路で車線を選び、混んだ所だけ速度をゆるめて、ペースの違う 3 台より先にゴールする
  アーケード。論理盤面は 360×640。一人用で、ライバルは対 CPU の相手ではない(「対戦」「対 CPU」とは
  書かない)。着順はゲームの中のペース車に対する結果で、プレイヤー間の順位ではない
  (PRODUCT_PRINCIPLES.md「Core の画面に順位は出ない」の 1 文。前例は Hearts §3.2 の清算画面)。
- **100 面のはしご。クリアは 1 位。**既クリアはいつでも再走でき、開放の最前線は戻らない。
  難易度選択・Free Run・タイムアタック・デイリーは無い。「2 位以内へ緩める」案は仕様ではなく、
  計画の判断待ちに残しただけ。
- **速度は自動で全開。指を下へ引いた量に比例して減速し、上へ動かしても何も起きない片側式。**
  第 2 指か ▼ の長押しで最大減速。`ot.prefs` の Buttons モード(◀ ▶ ▼)ではドラッグは無効。
  キーは ← → / A D、↓ / S、Space / Enter、P / Esc。**2 軸 1 本指の操作は、実機 2 台の Phase 0
  (空コースを 30 秒走って意図しない減速時間が 3% 未満)を通すまで凍結しない。**通らなければ
  既定は「横ドラッグ + ▼ 長押し」。
- **衝突 = 速度 0 を 0.5 秒保持 + 操舵ロック 0.3 秒 + 点滅 0.8 秒。**ライフ・燃料・ニトロ・
  ピックアップ・ガレージ・コンティニューは無い。**死は無い** — どのレースも着順で終わる。
  「Bump 1 回の損」が「ゲート前の減速の損」の 2 倍以上であることをテストで固定する(値は実装で測る)。
- 交通は全車が同じ速度で走り、コース座標では静止して見える。生成は正解ルートを先に彫る構成法で、
  探索は無く必ず成功する。交通は (seed, level) で決定的で、同じ面は毎回同じコース。
- ライバル 3 台は参照ボットと同じ純関数のプランナー `planLane` を共有する。レーサー同士の接触は
  罰なし。ペースは凍結表 `RIVAL_PACE[100]`(ラバーバンドなし — プレイヤーの位置・順位・連敗に
  依存しない)。**クリアの実体は最速ライバル 1 台のタイムであり、§13 にそう書く。**
- **Lv11 以降は全開では通れない行を入れて減速を必須にし、Lv21 以降は減速しないボット(Rusher)が
  1 位になれないことをテストで固定する。**Lv1 から毎面、減速すると楽に通れる行を 1 つ以上入れる。
- 進行バーは自分とライバル 3 台の静的な目盛り(色・点滅・音なし)。着順は静的な `n/4`。
  **レースの経過時間はどこにも出さない。**結果カードは着順 `n/4` と Bumps n だけ。
  共有の `outcome` が `completed` になるのは 1 位のときだけ。Rank / Ranking は使わない。
- 助けは即時・無料・同一コースの再走と、操作の助け(Buttons モード・↓ キー・▼)。Undo・Hint・
  レーシングラインは作らない。↻ は確認なしの即時リトライ(アーケードの形)。
- 保存キーは `ot.progress`(開放の最前線)/ `ot.stats`(`played`・総プレイ秒)/ `ot.flags` /
  `ot.prefs`(Buttons モード)の 4 つ。**途中保存は作らない。**バックグラウンドで止まり、復帰しても
  タップまで再開しない。途中保存が無いので画面を離れればランは終わる(プレイ秒は計上する)。Back の
  正確な扱いは Phase 2 で決める(計画の未決事項)。`played` は開始(`ready` → `running`)で 1 回、Retry も
  1 回(Bubble Pop §10)。
- 音はエンジン音・連続音・速度で上がるピッチ・追い抜きの音・クラクションを作らない。Bump は短い
  1 音、1 位のゴールは既存の完了音(当て方は未決)。路面の破線は Reduced Motion でも止めない(速度の唯一の連続信号)。
- 比較対象(Road Fighter / Spy Hunter / OutRun)との対応は §14 にだけ書き、**配色・車体シルエット・
  パトカー・燃料計を複製しない**。製品名はアプリにもストア文言にも書かない
  ([BRAND.md](BRAND.md)「自社タイトルと比較対象の名前」)。
- 未決(計画の「未決事項」。Phase 2 でここに決める): 操作の定数と既定(Phase 0)、Drag モードでの ▼、
  ライバル全車ゴール後の扱い、決勝(10 の倍数)の形、一時停止の操作、blur で止めるか、Back の扱い、
  音の当て方、結果カードの第一ボタン、車線数とコース長の面ごとの値、統計画面の中身。
- Quick Rules の文案(仮。3 ステップ。**2 は Phase 0 の結果で書き直す** — 通らなければ「▼ を長押しして
  ゆるめる」)
  1. 指を横にすべらせて車線を変える。アクセルは自動で、速度は勝手に上がる。
  2. 混んだところは指を下へ引いてゆるめる。ぶつかると止まる — ゆるめるほうが速い。
  3. ペースの違う 3 台より先にゴールすれば、次の面が開く。
