# 2026-11-03: Web先行公開3本 — No. 68〜70

製品オーナーの「3つくらい追加、UIを他のゲームに揃えてWeb公開まで」という依頼を実装する。
Cannon Duel / Hidden Fleet / Ice Trailの3ジャンルを選ぶ回答を受領した。
仮題には同名作があるため、公開名を Ridge Cannons / Fleet Search / Frost Route とした。
名前の検索範囲は各ルール文書に記録。商標クリアランスや母語話者レビューは未実施。

## 実装

共通のホーム、Quick Rules(図付き3ステップ)、統計、結果カード、結果シェアを使う。
3難易度、seedと入力列による途中再開、進行中の置き換え確認、14言語を備える。
砲撃は固定刻みの物理計算、艦隊CPUは公開された命中・外れだけから推定する。
氷パズルは最大648状態のBFSで生成候補の可解性を判定し、ヒントと待ったを提供する。
web-betaなのでnativeの扉・正式収録65本・Club Houseは変更しない。

## 検証

- 新作のエンジン・保存・React操作テスト34件を追加。専用テストは通過。
- 共通契約・i18n・チャンネル・一覧・保存キーの検査を実施。
  端末負荷による既存画面テストのタイムアウトは、対象3ファイルを単独再実行し88件通過。
- 360×640のブラウザーで主操作と広告100px枠の分離、艦隊配置・攻撃、
  パズルのヒント・待った・最短11手でのクリアを確認。
- 全体lint・型・native/webビルド・広告分離・ブランド原則・容量ゲート通過。
  新作チャンクのgzipは約13.4 / 16.5 / 14.9KB。Web総量は約46.8KB増、初期ロードは約0.8KB増。
  3本の追加を容量ベースラインに記録した。
- 319×640、ドイツ語・ライト・動き軽減で砲撃・艦隊配置・攻撃とキーボード操作を確認。
  砲撃は勝利と統計更新まで、艦隊は768×1024の盤面と自艦隊表示も確認。
  ホームのクラス名と艦隊のSVG追加後の罫線を修正した。
- ローカルの全ゲーム試験は重複型検査と並走してタイムアウトしたため中止。
  新作と共通ゲートを1ワーカーで再実行し、34ファイル・1,214件すべて成功。
  全体試験はCIと公開ワークフローで確認する。
- 実機のAndroid/iOS WebView、母語話者による翻訳の意味・自然さは未確認。
