# No. 62–66 — インベーダーを含む5本の追加とWeb公開

2026-10-23。製品オーナーから「インベーダーを含む5件のゲーム追加」と「Web版への反映まで」
の依頼。既存61本に次の5本をWeb先行公開として加える。

| ID / タイトル                   | 内容                                               | 助け                                   |
| ------------------------------- | -------------------------------------------------- | -------------------------------------- |
| invaders / Invaders             | 編隊を迎撃するシューティング、自動射撃、20ステージ | 即時リトライ                           |
| falling-blocks / Falling Blocks | 落ちるブロックを移動・回転して横一列を消す         | 落下位置・次のピース表示、即時リトライ |
| paddle-rally / Paddle Rally     | CPUとラリー、下のパドルを操作、5点先取             | 即時リトライ                           |
| hanoi-towers / Hanoi Towers     | 3・4・5枚の円盤を大きさ順のまま右の塔へ            | 無制限Undo                             |
| maze-escape / Maze Escape       | 5×5・7×7・9×9の生成迷路を出口へ                    | Undo / 次の一歩のHint                  |

ゲーム固有仕様は各RULES文書を正とする。追加パッケージ、外部画像、API、Club Houseの登録を
必要とせず、既存の正式収録41本と既存保存データを変えない。全5本に独立した保存、
3ステップ以内のQuick Rules、統計、結果共有を備える。タッチ・マウス・キーボードを扱う。
お気に入り上限は全66本を収めるため64から128へ拡大する（既存レコード互換）。

ゲーム名と素材は既存作品のロゴ・キャラクター・音源をコピーしない。
物理端末での性能確認、人間による14言語の自然さ確認、商標調査は未実施であり、
Web先行公開とアプリへの正式収録を区別する。

## 公開手順

pixapps-landingのWEB_BETA_GAME_IDSに5本を追加。
既存のPublish Simple Games (web)ワークフローへ確定SHAと公開用ブランチを指定し、
AdMax設定を維持して配信物を生成する。ソースPRのCIと生成物の検証が通過してから
両PRを統合し、本番へ配信する。
本番配信物の生成はワークフローが行い、ローカルの広告・計測IDなしビルドで上書きしない。
配信後に本番URLと配信物を確認する。
