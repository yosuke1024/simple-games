# No. 57–61 — 5ゲームの追加とWeb公開

2026-10-23。製品オーナーの依頼は「次のゲーム5本を検討し、実装からWeb公開まで」。
既存のmainは正式収録41本、Web先行公開15本の合計56本。今回もWeb先行公開として5本を追加する。

## 選定

| ID / タイトル                 | 選んだ理由                                                           | この版の範囲                                   |
| ----------------------------- | -------------------------------------------------------------------- | ---------------------------------------------- |
| `light-grid` / Light Grid     | 反転の重なりを考える。既存の数字・領域・配線パズルと操作の意味が違う | 解ける3/4/5角の盤、Undo、解に基づくHint        |
| `color-flood` / Color Flood   | 領域の成長順を考える。Water SortやGem Swapと異なる色パズル           | 3サイズ、6色＋記号、手数制限なし、Undo         |
| `three-peaks` / Three Peaks   | 1つ違いの札を取りながら次の札を開く。既存ソリティアより操作が少ない  | 52枚の1人遊び、A–K接続、Undo、同じ配札へ再挑戦 |
| `nim` / Nim                   | 小さな完全情報ゲーム。CPU相手に数の戦略を試せる                      | 最後を取る側が勝ち、3難度、1往復Undo           |
| `knight-tour` / Knight’s Tour | 駒の移動制約と経路計画。Number Pathとは異なりナイトの跳躍だけを使う  | 5/6/8角、証明済みの開始配置、合法手表示、Undo  |

5本ともローカルで完結し、追加パッケージ・API・課金・コンテンツ配信を必要としない。
ゲーム間のimportを作らず、共有側はレジストリ・色・保存領域・既存の統合ガードだけを更新する。
色以外の数字・形・位置でも盤面を区別でき、タップとキーボードで操作できる形にする。
統計は記録のためだけ。制限時間・再訪の義務・報酬によるロックは導入しない。

## 規則の参考とこの実装の判断

既存コードや素材をコピーせず、規則を照合して独立に実装する。

- 点灯反転: [Simon Tatham, Flip](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/flip.html)。
  上下左右＋自分の十字反転を採用。この版は全消灯を目標にする。
- 領域拡張: [Simon Tatham, Flood](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/flood.html)。
  この版は手数上限を設けず、接している色だけを選べるようにし、手詰まりを作らない。
- カード: [Solitaire City, Tri-Peaks](https://www.solitairecity.com/iPhone/Tri-Peaks.shtml)。
  52枚・3山・露出札・隣接ランク・A–K循環の規則を照合。時間ボーナスは採らない。
- 石取り: [MathWorld, Nim](https://mathworld.wolfram.com/Nim.html)。最後の石を取った側の勝ち。
- 騎士の巡回: [MathWorld, Knight's Tour](https://mathworld.wolfram.com/KnightsTour.html)。
  閉路へ戻る必要のない巡回を採用する。

ゲーム固有の詳細・保存形式・操作・テストは各 `*_RULES.md` が正本。
ゲーム名の商標・ストア検索、実機確認、翻訳の自然さの人間レビューは実施していない。
今回は既存のWeb先行公開の範囲。アプリへの正式収録は別の判断となる。

## 配信

既存の `pixapps.ai/simple-games/play/` を使う。
`simple-games` の変更をPRのCIで検査し、`pixapps-landing` の許容リストと配信物を同期する。
本番の広告・計測設定は既存の公開ワークフローに任せ、値・掲載位置・プライバシー方針を変えない。
`channel: 'web-beta'`、ホームとQuick Rulesに既存のベータ注意表示、独立した保存キー。
正式収録41本・ストア文面・Club Houseの登録一覧は変更しない。

## 検証と公開記録

実装時のローカル検証:

- 新作のエンジン・保存・画面テスト78件が合格。Light Gridは1,500 seed、
  Color Floodは240 seed、Knight’s Tourは全96通りの巡回配置を検証。
- 共通の構造・登録・保存キー・翻訳・Club境界など52ファイル、1,731件を検証。
  最初の実行で見つかった戻るボタンとショートカットの検査4件を修正し、
  該当ガード488件を再実行して合格。端末データ削除の2件は同時実行負荷で
  タイムアウトしたため、タイムアウト設定を変えず単独で再実行し合格。
- ESLint、アプリとブランドパッケージの型検査、native / Webのビルド、
  ブランド原則、広告・計測コードの分離、iOS版番号、サイズGateが合格。
  ダミーGA IDを与えたnativeビルドでも計測IDが含まれないことを検証。
- 5本の独立チャンクは各gzip約10〜14KB。追加後のサイズ実測を基準値へ記録。
- ブラウザで5本を360px幅で操作。Light Grid / Color Floodはクリアまで、
  Three Peaksは札取り・ドロー・Undo、NimはCPU応答と1往復Undo、
  Knight’s Tourは合法手移動とUndoを確認。Three Peaksは320px幅も確認。
  ヒントの表示・読み上げラベル、確認ダイアログの背景操作、途中保存の時間計上は
  相互レビューで修正し、回帰テストを追加した。

公開は本変更のPRと `pixapps-landing` の同期PRで管理する。公開ワークフローは
このソースの確定SHAで全テストと配信物検査を再実行し、合格後に本番へ反映する。
ローカルでの合格は本番反映の証拠とは扱わず、配信後のURLで別途確認する。

## 公開前の意匠見直し (2026-10-23)

本体PR #257のマージ後、製品オーナーから「Light Gridのヒントが分からない」、
「Knight’s Tourの駒をChessと同じにする」、「5本ともシンプルなまま格好良くする」
という指示を受けた。旧版の配信ワークフローは公開前に停止した。

- Light Grid: 押す行・列を明記し、番号付きの対象マスと反転する隣接マスを区別。
  ヒントは操作を代行しない。盤とチュートリアルを落ち着いた配色のSVGへ統一。
- Color Flood: 記号をSVGへ統一し、連結範囲の輪郭と進捗を表示。
- Three Peaks: 角のランクと中央のスート、独立した裏模様、山札と捨て札の配置を整備。
  裏向きの札には表の図形やスート色を含めない。
- Nim: 石を細い駒として整列し、取り除く駒と残り数を確定前に表示。
- Knight’s Tour: Chessのナイトの図形を共通の描画部品に抽出し、同じ色と図形で使用。
  チェッカー盤・訪問済み番号・合法手の点を整理。

盤面・余白・枠線を整え、既存のゲーム固有アクセント色は維持する。
320×568の広告付き表示では操作欄が隠れる問題を検出したため、ゲームのスクロール範囲を
広告の上に制限した。ブラウザで360×740と320×568の表示と基本操作を確認している。
実機確認や人間による翻訳レビューとは区別する。公開には見直し後のソースSHAを使用する。

見直し後のローカル検証では関連41ファイル・1,033件が合格し、追加したナイト盤の
コントラスト検査2件も合格。ESLint、TypeScript、native/Webビルド、サイズGate、
ブランド原則、配信物の広告・計測分離を再確認した。総gzip増加は約5KB。
Chessのナイトと共通化した図形は、抽出前の座標・描画順序と一致する。

公開版の確定記録（ソースSHA・配信ワークフロー・Cloudflare反映・本番確認）は
[pixapps-landing #207](https://github.com/yosuke1024/pixapps-landing/pull/207)に集約する。
意匠見直しのゲームコードは`3570e9d2be15bbc6f2d5db0d5001691f603c7984`で固定し、
その後の公開記録の文書補足は配信物を変更しない。
