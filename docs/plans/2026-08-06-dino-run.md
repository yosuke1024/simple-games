## 名前と見た目

`Dino Run` はジャンル名に近い一般名で、`Water Sort` `Sliding Puzzle` `Block Puzzle` と
同じ「ジャンルそのものを名前にする」流儀に揃う([BRAND.md](../BRAND.md): タイトルは
英語の固有名詞・全言語で同一表記)。

**Chrome の恐竜画面を複製したのではない。** 走者・サボテン・鳥はこの収録のために
描いた矩形スプライトで、盤面比・色・UI はシリーズの下地に従う。ジャンルを借り、
見た目は借りない(BRAND.md「他ゲームの見た目を模倣しない」)。

| ゲーム   | アクセント | ライト    | ダーク    | 選んだ理由                                       |
| -------- | ---------- | --------- | --------- | ------------------------------------------------ |
| Dino Run | 砂漠の草   | `#6e7a34` | `#b6c274` | Solitaire の緑と Brick Breaker の黄土の間の空き |

障害物をアクセント、走者と地面をインクで描く。**色が形より先に「これは邪魔物だ」と
言う**ので、鳥かサボテンかを読む前に避ける判断が始められる。

## 設計で迷い、決めたところ

**1. しゃがみをどう入力するか。** 「タップ = ジャンプ / 長押し = しゃがみ」を最初に
検討したが、長押しの判定が確定するまでの数十 ms に必ず小さなジャンプが混ざる。
頭の高さの鳥に対してその跳ねは致命的で、「しゃがもうとしたら跳んで死ぬ」入力になる。
**板の下に 2 つのボタンを置き、コースのタップはジャンプにも割り当てる**形にした。
指で押す場所を探す時間が勝敗を決める遊びなので、当たり判定は大きく、名前も付く
(スクリーンリーダーからも触れる)。キーボードは Space/↑/W と ↓/S。

**2. 間隔を秒で決める。** 速度は 200px/s から 460px/s まで上がる。間隔をピクセルで
決めると、開始時に公平だった隙間が終盤には物理的に飛び越せない幅になる。
**間隔は秒で引き、最短 0.78 秒**(ジャンプの滞空 0.61 秒より長い)とした。
難易度を上げるのは速度だけで、密度は最後まで増やさない。

**3. 高い鳥を「何もしない」問いにした。** 立って走る限り当たらない鳥を 1 種類だけ
置いた。反射でジャンプすると当たる、この遊びで唯一「押さない」が正解の形である。
その代わり**高い鳥の後ろには 1.1 秒を空ける** — 頭上にいる間に次の障害物のために
飛ばされるなら、それは避けられない死になるため。

**4. ライフも復活も作らない。** 1 度触れたら終わり。エンドレスでリトライが即時・
無料である以上、失敗は安い。「もう少し生き延びる仕組み」は、あとから売り物にできる
形をしている — この製品はその形を持たない([PRODUCT_PRINCIPLES.md](../PRODUCT_PRINCIPLES.md))。

**5. 保存しない。** リアルタイムのコースを復元しても「開いた瞬間にサボテンが目の前に
ある」ものにしかならない。アーケード 2 本(Brick Breaker / Sky Fighter)と同じ判断で、
保存キーは `dr.stats` と `dr.flags` の 2 つだけ。

**6. レビュー依頼の数え方。** 走りは数秒で終わることがある。全部を「1 ゲーム完了」と
数えると、10 秒遊んだ人にストア評価を尋ねることになる。**スコア 100 以上のランだけ**
`recordGameCompleted()` を呼ぶ([REVIEW_PROMPT_POLICY.md](../REVIEW_PROMPT_POLICY.md))。

**7. スプライトは絵として書く。** 最初の版は矩形の座標配列で走者を描き、数字としては
妥当なのに**恐竜に見えなかった**(頭が小さく胴が細い)。編集中に形が見えないことが
原因だったので、`ui/components/sprites.ts` を `#` / `.` / 目の穴 `o` のドット絵に
書き換えた。ソースが画面と同じものを見せるので、頭の大きさの間違いが差分で分かる。
走者は 19×20 マス(38×40px)。

## 作らなかったもの

- **昼夜の切り替え**: 画面の明暗はアプリ設定がすでに持っている。ゲームが勝手に
  反転させない。
- **二段ジャンプ / スライディングの距離**: どんな間隔も飛び越せるようになり、
  コースが問いを出さなくなる。
- **デイリー**: 生成はシード決定的なので、必要になれば後から足せる。
- **オンラインランキング**: 追加の固定インフラ費を作らない。
