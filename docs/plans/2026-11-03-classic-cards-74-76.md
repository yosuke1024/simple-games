# 大富豪・七並べ・ババ抜き (No. 74〜76)

オーナーの「3ゲームを追加し、既存と同等のUXにしてWeb公開まで」の依頼と、3本の明示指定に基づく。重複回避を優先した初期候補は採用せず、定番トランプ3本を選んだ。

## 実装

- Daifugo: 4人戦。ジョーカー1枚、同数出し、革命、8切り、スペ3返し、次局の順位別交換。初回は♦3の持ち主から。CPUは自分の手札と公開情報だけを使う。
- Sevens: 4枚の7から同スートを広げる4人戦。3パス、4回目は確認後に脱落して手札公開。公開済みの孤立札を7とつながるまでアンカーにしない。
- Old Maid: ジョーカー1枚の4人戦。ペア整理、隣の生存者から伏せ札を選ぶ。CPUは枚数だけからランダムに引く。CPUの非公開札をDOM/ariaに出さない。
- ルール正本はそれぞれ `DAIFUGO_RULES.md` / `SEVENS_RULES.md` / `OLD_MAID_RULES.md`。ローカルルールを明示する。
- 各ゲーム専用の純粋TSエンジン・保存スキーマ・14言語・SVGカード・CSSを持つ。共通のホーム、説明、結果、再挑戦、広告、共有を再利用する。
- 途中保存、ブラウザの直接入口、統計、キーボード、Reduced Motion、CPUの背景/ダイアログ停止、アンマウント時の時間計上を実装。伏せ札があるのでUndoを設けない。
- Web beta。アプリ正式収録65本は変更しない。全76エントリ（正式65、beta9、取り下げ2）。
