# Chain Territory (No. 71)

## ルール

5列×6行でプレイヤーとCPUが交互に1個置く。空マスまたは自分のマスだけに置ける。
隣接は上下左右。角は2個、辺は3個、内部は4個で分裂し、各隣へ1個ずつ送る。
送られたマスは手番側の所有に変わり、満杯ならさらに連鎖する。
両者が最初の1手を置いた後、相手の玉が全て無くなれば勝利。全てを所有した時点で
連鎖を止めるため、満杯盤で無限の連鎖は起きない。プレイヤーは先手。
Easyは合法手からseedによる選択、Normalは獲得と危険度の評価、Hardは相手の応手まで読む。
CPUは同じ公開盤面だけを見る。待ったは自分の直前手まで(相手の応手も戻す)。
連鎖を段階表示し、上限間近は容量の小点で示す。プレイヤーの丸とCPUの菱形で色以外も区別する。
最短手数は勝った局だけ。途中再開はCPU手番も保持し、前面へ戻ったら応手を再開する。
保存キー: ct.saveGame / ct.stats / ct.flags / ct.prefs。最大256手(安定盤の容量未満で必ず終局)。

## 共通契約

2026-11-03、製品オーナーの追加3本とWeb公開の依頼、および候補3本への承認による。
Web先行公開のみ。正式収録65本・Club House・Nearbyには加えない。
純粋TypeScriptのゲーム層、ゲームごとの保存、14言語、図解3ステップを持つ。
GameHomeHeader / GameArtwork / WebBetaNotice / BannerSlot / ResultAdSlot / ShareActionを使う。
操作中の確認は背景をinertにし、キー入力・CPU・再生を停止する。非表示・退出時は保存する。
動き軽減では演出を省略し、タイマー・イベント購読はアンマウントで解除する。
保存はv1のseedと合法手列から再構成し、不正値・過長履歴・終了後入力を拒否する。
再挑戦前の置換は既存の確認を使う。進行と統計は端末内のみ、課金・通信・時間制限は無い。
英語が原文、jaを含む13言語はAI作成。人による翻訳レビューは未実施。
高リスク文言は追加せず、既存シェル文言を使う。
