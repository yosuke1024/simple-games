# Simple Games — オフラインポリシー

## 基本方針

**オフラインは正常系である。** 機内モードはエラーではない。
すべてのゲーム機能は、一度もオンライン接続していない端末の初回起動から利用できる。

## 初回起動

以下を初回オンライン取得に依存させない。すべてアプリに同梱する。

- ゲームデータ / チュートリアル / 翻訳 / フォント(システムフォントのみ使用) /
  アイコン / 効果音(WebAudio で合成、外部アセット不要) / Daily Challenge /
  ゲームルール / 初期設定

## オフラインで利用可能であるべき機能(全機能)

初回起動、チュートリアル、Classic、Daily Challenge、New Game、Restart、Resume、
Undo、Hint、Add Numbers、ゲームクリア、ゲームオーバー、設定、統計、言語変更、
テーマ変更、効果音、振動、Reduced Motion、ローカルデータ削除。

## ネットワーク障害時の動作

- エラーダイアログを表示しない
- 広告取得をスキップする(バナー枠は静かな空きスペースのまま)
- Remote Config 取得をスキップし、アプリ内デフォルト+最終取得値を使用する
- Analytics 送信失敗を無視する
- ゲーム開始を遅延させない / ゲーム進行を変更しない
- オンライン時より機能を制限しない

## 実装ルール

- ネットワークを使う処理(広告 / Remote Config / Analytics)はすべて
  fire-and-forget とし、失敗を握りつぶす(ログのみ)。
- ネットワーク処理の完了を UI 描画・ゲーム開始・画面遷移の条件にしない。
- 「オフラインです」という表示を毎回出さない。
- Daily Challenge は端末のローカル日付を Seed に使い、サーバー時刻を使わない。

## ネットワーク権限の用途(これ以外に使わない)

広告取得 / 広告同意 / Remote Config / Analytics
