# Number Recall — 正式ゲームルール

この文書は Simple Games 収録タイトル「Number Recall(位置記憶)」の唯一の
ルールソースである。実装(`apps/simple-games/src/games/number-recall/game/`)、
テスト、Quick Rules はすべてこの文書に従う。

ブランド原則([PRODUCT_PRINCIPLES.md](PRODUCT_PRINCIPLES.md))はこの文書より上位にある。

脳トレドリル 3 本に共通するジャンル原則は
[SCHULTE_TABLE_RULES.md](SCHULTE_TABLE_RULES.md) §14 にある。

## 1. 盤面

- N×N のマス。N は 3 / 4 / 5 のいずれか。
- そのうち **K マス**にだけ数字タイルが置かれる(`1` から `K` まで、重複なし)。
  残りは空きマス。K < N² であり、空きマスは常に存在する。
- **タイルには数字だけを描く。画像・記号は使わない**
  ([I18N_POLICY.md](I18N_POLICY.md))。
- タイルの伏せ面は無地(数字なし)。**色だけで表裏を区別しない** — 面の形
  (数字が見えるか、無地か)が第一の手がかりである。

## 2. 勝利条件

`1` から `K` までを、伏せられた状態のまま順にタップし切った状態。

## 3. 操作 — 覚える時間はプレイヤーが決める

このゲームの中心設計であり、「急かさない」をこのジャンルで成立させている場所である。

1. **記憶フェーズ**: ラウンド開始時、K 枚のタイルはすべて**表向き**で置かれ、
   数字が見えている。**制限時間はない。**好きなだけ眺めてよい。
2. **`1` をタップした瞬間**、`1` 以外のタイルがすべて伏せられる。
   これが記憶フェーズの終わりであり、**終わらせるのは常にプレイヤーの操作**である。
3. **再現フェーズ**: 以後は記憶だけで `2`, `3`, …, `K` の順にタップする。
   正解したタイルは表向きに戻り、数字が見えたまま固定される。
4. **誤タップでラウンド失敗**(§4)。

- **端末が記憶時間を区切ることはしない。** 「n 秒間だけ見せる」形は
  このジャンルの定番だが、覚える時間を端末が切るのは「急かさない」の正面からの
  違反である([MEMORY_MATCH_RULES.md](MEMORY_MATCH_RULES.md) §3 の
  「見るのをやめるのは常にプレイヤーの操作である」と同じ判断)。
- **眺めていた時間も記録に含める**(§5)。長く見るほど確実になり、短く見るほど
  速くなる — **このトレードオフ自体がこのゲームの遊びである。**
  時間を計るのに制限時間を作らなくてよいのは、この構造による。
- 空きマスへのタップ、および既に表向きのタイルへのタップは**何も起こさない**
  (無効な手。失敗にはしない)。押す相手を間違えたのではなく、
  盤面でないものを押しただけである。

## 4. ラウンド失敗と再挑戦

- 伏せられたタイルのうち、**次に押すべきもの以外**をタップするとラウンド失敗。
- 失敗したら盤面を**すべて表向きにして正解の配置を見せる**。押すべきだった
  タイルには印を付ける。
- **この開示に時間制限を置かない。** 見終わったらプレイヤーが再挑戦を選ぶ。
  自動で消える演出にすると、覚える時間を端末が切らないという §3 の判断と矛盾する。
- 再挑戦は即時・無料。**ただし同じレベルの新しい配置で始まる**(§8)。

## 5. 時間と回数

- **時間はプレイ中に表示しない。** 記憶フェーズの秒数も含めて内部で記録し、
  完了画面と統計でのみ見せる。
- **制限時間はない。時間切れも存在しない**(ジャンル原則)。
- レベルごとの記録は **最短時間** のみ。失敗回数は記録の対象にしない
  (失敗はもう新しい配置で流れており、比較する相手がない)。
- 統計には **一発クリア数**(そのレベルを最初のラウンドで完了した回数)を持つ。
  事実として表示するだけで、煽らない。

## 6. 配置生成

- `N²` マスから K マスを seed 由来の乱数で選び、選ばれたマスに `1..K` を
  seed 由来の順で割り当てる。
- 同じ seed は常に同じ配置を返す(golden テストで固定する)。
- **配置に制約は課さない。** 「連番が隣り合わない」等の条件を足すと引き直しが
  発生し、配置が偏る。散らばりは乱数に任せる。

不変条件:

- タイルはちょうど K 枚。`1..K` が過不足なく 1 度ずつ現れる。
- 2 枚のタイルが同じマスに乗らない。
- 同じ seed は常に同じ配置を返す。

## 7. レベル(1〜100)

level から (盤面サイズ, タイル数 K, seed) を決定的に導出する。
seed は `recall-level-<n>-r<attempt>`(attempt は §8 の挑戦回数。初回は 0)。

| レベル帯 | サイズ | タイル数 K | 意図                         |
| -------- | ------ | ---------- | ---------------------------- |
| 1–15     | 3×3    | 3 → 5      | 3 枚から。仕組みを覚える     |
| 16–55    | 4×4    | 5 → 9      | 標準の広さ。ここが最も長い帯 |
| 56–100   | 5×5    | 9 → 12     | 本命。広さと枚数が同時に効く |

各帯の中では K を線形に増やす(帯の先頭が下限、末尾が上限)。
**新しいサイズは前の帯の上限と同じ K から始める** — サイズと枚数を同時に
上げると 2 つの跳躍が重なる([SLIDING_PUZZLE_RULES.md](SLIDING_PUZZLE_RULES.md)
§6 と同じ考え方)。

- レベルは順番に解放する(クリアした level の次が解放)。
- 解放済みレベルはいつでも選び直せる。**ただし配置は挑戦ごとに変わる**(§8)。
- 各レベルの **最短時間** を記録する。

## 8. 再挑戦で配置を変える理由(Memory Match と逆の結論)

[MEMORY_MATCH_RULES.md](MEMORY_MATCH_RULES.md) は**同じ盤面への再挑戦**を
無料の助けにしている。このゲームは逆に、**同じレベルの新しい配置**を出す。
同じ収録の中で結論が割れているので、理由を残す。

- Memory Match の中身は「めくって、覚えて、ペアを見つける」ことであり、
  同じ盤面をやり直しても**まだ全部は見えていない**。再挑戦は依然としてゲームである。
- Number Recall は開始時に**全部見えている。** 失敗時にも正解を全部見せる(§4)。
  同じ配置を出せば、それは記憶ではなく**直前に見た答えの再生**になる。
  中身が空になる。
- したがって再挑戦は「同じ難しさの、別の問い」でなければならない。
  レベル(サイズと K)は固定し、seed だけを変える。

配置の seed は `recall-level-<n>-r<attempt>` で、attempt はそのレベルへの挑戦回数
(初回が 0)。**決定的**であり、乱数を端末時刻から引かない(同じ挑戦回目は
どの端末でも同じ配置)。挑戦回数は保存しないので、アプリを開き直せば
attempt は 0 に戻る — 記録に関わらない値なので、これでよい。

## 9. デイリーチャレンジ

- 1 日 1 課題。seed は `recall-daily-<YYYY-MM-DD>`(端末のローカル日付のみ)。
- **5×5 / K = 9 固定。** 曜日で難易度を変えない。
- 失敗した場合の再挑戦も**同じ日付の中で配置が変わる**(§8 と同じ理由。
  seed は `recall-daily-<date>-r<attempt>`)。
  **達成として記録されるのは完了したラウンドの時間**である。
- 過去 30 日に遡って挑戦できる。過去の日は無条件に開く。
- 達成した日は記録する。**ストリークは数えない・表示しない。**

## 10. Undo と Hint

- **Undo は作らない。** タップは記憶の主張そのものであり、取り消せるなら
  記憶を試していない。1 手戻して押し直せる形は、このゲームを
  「総当たりで当てる遊び」に変えてしまう。
- **Hint は作らない。** このゲームで示せるヒントは「次のタイルの位置」しかなく、
  それは答えそのものである。
- **代わりに、同じレベルへの即時・無料の再挑戦を出す**(§8)。無制限。
  これがこのゲームの「助け」である。
- **ライフ・復活・「もう 1 回だけ見る」を作らない。** どれも後から売り物に
  できる形をしている(Bunny Hop §4 と同じ判断)。失敗は安く、再挑戦は無料である。

## 11. 統計

- サイズ別(3×3 / 4×4 / 5×5)に: プレイ回数(ラウンド単位)、完了回数、
  最短時間、合計プレイ時間、**一発クリア数**。
- レベル進行: 到達レベル、クリア済みレベル数。
- デイリー: 達成日数(ストリークなし)。
- スコアは持たない。
- クリア画面: そのレベル(デイリーならその日)に記録があれば、記録との差を符号付きで
  添える(`+0:18` = 記録より遅い / `−0:05` = 記録を縮めた)。比べる相手は自分の
  記録だけで、初めてのクリアには何も添えない(`ui/components/BestDelta.tsx`)。

## 12. 中断と再開

- **途中のゲームは保存しない。** 保存キーは `nr.progress` / `nr.stats` /
  `nr.flags` の 3 つだけ。
- 理由: 1 ラウンドが数秒から十数秒で終わり、中身は**短期記憶を保っていること**
  である。アプリを閉じた時点でその記憶は残っていないので、再開しても
  「見たはずの配置を思い出せない盤面」を配ることにしかならない。
  記憶フェーズからやり直すのが唯一誠実な扱いであり、それは新しいラウンドと同じである。
- 画面を離れた時点で、そのラウンドは破棄される。統計の**プレイ回数には数えるが、
  完了回数には数えない**。
- 保存の失敗でゲームを止めない。壊れた保存データは読み捨てて既定値に戻す。

## 13. Quick Rules(アプリ内チュートリアル)

3 ステップ以内・各ステップ原則 1 文・図中心。

1. 数字の位置を覚える。**時間制限はない。**
2. `1` を押すと残りが伏せられる。あとは順に押していく。
3. 間違えたら答えを見て、新しい配置でもう一度。

詳細は Landing Page(`https://pixapps.ai/simple-games/games/number-recall/<locale>/`)へ。
**ガイド公開までは Learn More を出さない**(`src/ui/landing.ts`)。

## 14. 演出とアクセシビリティ

- タイルが伏せられる/表になる変化は短いトランジションで示すが、
  **Reduced Motion が有効なら即時に切り替える**。
- **最後のタイルを当ててから結果カードが出るまでに約 1 秒置く**(`ui/useResultReveal.ts`)。
  すべて表に戻った盤面を見る時間であり、その間に押せるものはない。Reduced Motion
  では従来どおり即時に出す(失敗時のパネル §4 は盤面を隠さないので、間を置かない)。
- 各マスは「数字または伏せ・空き」「行・列」を読み上げられること。
  伏せたタイルは数字を読み上げない(読み上げが答えを配ることになる)。
- 5×5 でもタップ目標が小さくなりすぎないよう、盤面は列幅いっぱいまで使う
  (`width: min(100%, 420px)`。vw は使わない)。
- 次に押すべき数字は盤面の上に表示し、読み上げ対象にする。
- 表・伏せ・空きは**面の見た目**で区別する。色だけで区別しない。

## 15. 意図的な差分

ブランド原則により合わせないもの:

- 記憶時間のカウントダウン、制限時間(作らない。§3)
- 脳年齢・IQ・認知機能の主張(作らない。ジャンル原則)
- ライフ・復活・追加の閲覧(作らない。§10)
- ストリーク、オンラインランキング(作らない)

設計判断として合わせないもの:

- Undo / Hint(作らない。§10)
- 同じ配置での再挑戦(作らない。§8 — Memory Match とは逆の結論)
- 途中保存(作らない。§12)
- 6×6 以上のサイズ(採用しない)
