## これまでに決まったこと(2026-10-20 — オーナーが 5 本をまとめて採った提案の仕様と、計画の判断。詳細は計画)

- 7 枚の駒(大三角 2・中三角 1・小三角 2・正方形 1・平行四辺形 1)を 45° 刻みで回し、平行四辺形は裏返し、
  影絵に重ねず・はみ出さず・隙間なく収めれば完成。時間制限・手数制限・得点・星は無い。
- **図形は実行時に生成せず、同梱のカタログから出す。**パブリックドメインの伝統図形(由来 — 出典・刊行年・
  確認日 — を「意図的な差分」の下の「比較対象との対応」に書く)と自作図形。座標は自分で起こし、既存アプリの
  図形データ・画像・配色は見ない・写さない。カタログの全図形は、同梱した解をルールに通すと完成になること・
  面積が 7 枚の和と等しいことをテストで確かめる。
- Free Play は Easy / Medium / Hard(カタログの分類)、Daily は今日の 1 問だけ(カタログから日付で引く。
  過去日なし・ストリークなし — [PRODUCT_PRINCIPLES.md](PRODUCT_PRINCIPLES.md)「デイリーは今日の 1 問」)。
- 助けは **Undo(無料・無制限)**と、**Easy の影絵の内側の線**(駒の境界を薄く示す)、**Medium の固定 2 枚**
  (解の 2 枚を置いた状態で出す)。**Hint は作らない**(影絵も駒も全部見えていて、どこに何を置くかがパズル
  そのもの — [PEG_SOLITAIRE_RULES.md](PEG_SOLITAIRE_RULES.md) §6 と同じ判断)。
- 操作はドラッグで置く・タップで 45° 回す・ボタンで裏返す(提案のダブルタップは、タップ = 回転と区別できない
  ので採らない — 計画の意図的な差分。Phase 0 で確かめる)・頂点と辺に吸着。キーボードでも全操作ができる。
  **この項は Phase 0 を通るまで凍結しない**(通らなければ上の差し替え)。
- 座標は Z[√2](a + b√2)の厳密表現で持ち、吸着と完成判定は浮動小数を使わずに行う。完成は幾何で判定し、
  保存した解とは比べない(別解を認める)。実行時の探索は無い。
- 保存キーは `tn.saveGame` / `tn.saveDaily`(2 スロット規則 — `src/test/savedGameSlots.test.ts`)/
  `tn.progress` / `tn.stats` / `tn.flags` / `tn.prefs`。いまのスキャフォールドは `tn.stats` / `tn.flags` だけで、
  残りは本文の保存の節と同じコミットで `storage/keys.ts` と `src/app/gameKeys.test.ts` に足す。読み込みは
  fail-closed(重なる・はみ出す・知らない図形・完成済み・日付の過ぎたデイリーは読み捨て、黙って新しい図形を
  始めない)。
- プレイ中に時計を出さない。記録はティア別の解いた数とデイリーの達成日(詳細は未決 — 計画)。
- グリフは `⊿`(U+22BF)。Phase 1 で実測して確定した(この環境で被覆 11、タイルのインク 2.7〜2.9%、予備は同じ
  向きで大きい `◿` U+25FF — 計画「Phase 1 の実施結果」と `app/registry.ts` のコメント)。低スペック実機と
  iOS / Android のフォールバックは未確認。
- 他社の製品名(既存の tangram アプリ等)はアプリ内・ストア文言に書かない。比較は「意図的な差分」の節で
  だけ([BRAND.md](BRAND.md)「自社タイトルと比較対象の名前」)。題「Tangram」の商標・両ストアの検索は、
  確認日つきでここに記録する(未了)。
- 提案時の算術と試作の値(360 幅で小三角の脚 1 本が 43〜56px、グリフの被覆 49 など)は、実装で再現するまで
  「検証済み」と書かない。
- 未決(計画の「未決事項」。Phase 2 でここに決める): カタログの数とティアの目安、デイリーのティア
  (推奨 Medium)、図形の出し方(推奨: ティアごとの順番の列)、結果カードの第一ボタン、固定する 2 枚、置けない
  位置の扱い、吸着の半径と矢印の刻み、裏返しの入口、影絵の穴と名前、時間の記録、Undo の 1 操作と履歴、
  駒の塗り分け、題の確認、Phase 0 の数え方。

## Quick Rules(文案は仮。3 ステップ)

1. 駒をドラッグで置き、タップで回す(平行四辺形はボタンで裏返す)。
2. 7 枚すべてを使って、影の形にぴたりと重ねる。
3. 隙間もはみ出しも無くなれば完成。
