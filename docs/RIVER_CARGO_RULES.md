# River Cargo (No. 73)

2026-11-07: オーナーの指示によりアプリに正式収録(1.8.1)。Club House・Nearbyには加えない。

## ルール

船頭と荷物を左岸から右岸へ運ぶ。船頭は常に船と移動し、荷物用の席は別に数える。
荷物を選び「渡る」で移動。船頭のいない岸で危険な組み合わせを残せない。
2026-11-03、オーナーの「パターンが少なすぎる」という指摘を受け、定員・重さ・同乗条件の違う12問に拡張。
Easy / Normal / Hardに各4問を置き、全問を最初から選べる。
初回の各難易度1問目は公開済みの問題をそのまま維持する。

| 問題     | 荷物数 / 定員 | 追加の条件                                                      | 最短渡河数 |
| -------- | ------------- | --------------------------------------------------------------- | ---------- |
| easy-1   | 3 / 1         | オオカミ・ヤギ・キャベツの元の問題                              | 7          |
| easy-2   | 3 / 2         | 同じ3個を2席で運ぶ                                              | 3          |
| easy-3   | 4 / 2         | 木箱を追加、重さ上限3                                           | 5          |
| easy-4   | 4 / 2         | 危険な組なし、重さ上限3                                         | 5          |
| normal-1 | 4 / 1         | 元の3個と木箱                                                   | 9          |
| normal-2 | 4 / 2         | 毎回ヤギかキツネを乗せる                                        | 5          |
| normal-3 | 5 / 2         | オオカミとキツネは同船不可                                      | 5          |
| normal-4 | 5 / 2         | 重さ上限3                                                       | 7          |
| hard-1   | 6 / 2         | 元の問題：オオカミ・ヤギ・キャベツ・キツネ・ニワトリ・穀物      | 7          |
| hard-2   | 6 / 2         | 重さ上限3                                                       | 9          |
| hard-3   | 6 / 2         | 毎回ヤギかニワトリを乗せる                                      | 11         |
| hard-4   | 7 / 2         | 木箱追加、上限4、毎回ヤギかニワトリ、オオカミとキツネは同船不可 | 13         |

重さは単位を置かない整数。個々の荷物と、選択合計 / 上限を表示する。
必須の同乗者がある問題では帰りも条件を満たす必要があり、空船では渡れない。
危険な岸の組み合わせと同船禁止を区別して表示する。条件を満たさない操作は理由を示して実行しない。
全荷物が右岸ならクリア。BFSで最短手順を求め、Hintは次に乗せる荷物を名前と枠で示すだけ。
待ったは1往復ではなく1回の横断を戻す。再挑戦と次の問題へのボタンを提供する。
最短渡河数と、問題ごとの自分の最少渡河数を提供する。解放条件や達成率による誘導は置かない。

## 保存と互換

保存キー: rg.saveGame / rg.stats / rg.flags / rg.prefs。最大512横断、上限前に待った・再挑戦できる。
ゲーム保存と統計はv2、flagsとprefsはv1。puzzleIdと合法手列で再構成する。
v1の保存は難易度ごとの1問目へ対応させ、元の荷物順・危険な組・定員・最短手数を維持する。
v1の統計も同じ1問目に引き継ぎ、別の問題の記録と混ぜない。
正式収録でこのv2を凍結し、公開Webで採取した記録を `storage/releasedRecords.json` で固定する。
問題識別子と定義は保存の再現性のため固定する。

## 共通契約

2026-11-03、製品オーナーの追加3本とWeb公開の依頼、および候補3本への承認による。
2026-11-07に正式収録。Club House・Nearbyには加えない。
純粋TypeScriptのゲーム層、ゲームごとの保存、14言語、図解3ステップを持つ。
GameHomeHeader / GameArtwork / WebBetaNotice(正式収録では表示しない) / BannerSlot / ResultAdSlot / ShareActionを使う。
操作中の確認は背景をinertにし、キー入力・CPU・再生を停止する。非表示・退出時は保存する。
動き軽減では演出を省略し、タイマー・イベント購読はアンマウントで解除する。
保存は上記の問題識別子と合法手列から再構成し、不正値・過長履歴・終了後入力を拒否する。
再挑戦前の置換は既存の確認を使う。進行と統計は端末内のみ、課金・通信・時間制限は無い。
英語が原文、jaを含む13言語はAI作成。人による翻訳レビューは未実施。
高リスク文言は追加せず、既存シェル文言を使う。

## 名称と素材

2026-11-03、公開Webの完全一致検索でChain Territory / Marble Weave / River Cargoという
同名ゲームは確認できなかった。Prism LinesとRiver Passageは同名アプリがあったため採用しない。
検索は商標クリアランスではなく、商標DB・両ストアの全件調査は正式収録前に行う。2026-11-07: 1.8.2 の本番公開前に商標DB・両ストアを調べた(両ストアの検索、USPTO、J-PlatPat、TMview、WIPO は一部。各DBは既知の名前で検索が効くことを確かめてから0件と判断)。同名・紛らわしい名前のアプリ・ゲーム・商標は見つからず、題はそのまま使う(低リスク。法的クリアランスではない。WIPO の完全一致検索・EUIPO の直接検索など、エラーで実行できなかったものがある)。
盤面・キャラクター・図は自作SVG/CSS、音は既存サービスのみ。既存作品の素材・コードは使わない。
検証・公開記録は docs/plans/2026-11-03-three-more-games-71-73.md に残す。

## Artwork revision (2026-11-03)

オーナーの「ヤギ、オオカミ、キャベツの絵がしょぼすぎ」という指摘を受け、
単色の線画をオリジナルの塗りのあるSVGに描き直した。ヤギは角・耳・あごひげ、
オオカミは青灰色の毛・尖った耳・白い頬、キャベツは重なる葉で識別する。
キツネ、ニワトリ、穀物袋、木箱も同じ絵柄。素材の色はテーマ間で維持する。
基本の3荷物は左右の岸に名前付きの1列カード、絵は44px。
ゲーム状態は絵とラベル・選択枠・位置で伝え、色だけに依存しない。

さらに「可愛くない」というフィードバックを受け、輪郭を丸くし、大きな目・小さな笑顔・頬の色を追加。キャベツにも顔を描いた。
