それまでは計画 [2026-10-19-chess-gem-swap-pipe-link-bounce-up-echo-pads.md](plans/2026-10-19-chess-gem-swap-pipe-link-bounce-up-echo-pads.md)

## これまでに決まったこと(2026-10-19・20 の製品オーナーの判断。理由と詳細は計画の 51 節)

- **端末が再生を進めることを例外として認める。**条件は次の 4 つ。
  - 再生は ▶ のタップで始める。
  - 再生中はいつでも Stop できる。
  - 聞き直しは無料・無制限。ただし許すのは、入力の前と失敗の後だけ。
  - Pace は Calm / Normal / Quick。

  この文書には例外とその理由を書く。理由は、見終わってから返す記憶では見る回数をプレイヤーが
  決められるので「急かさない」を保てる、というもの。

- 失敗するとその run は終わる。再挑戦は同じレベルの新しい列で行う(seed の attempt を +1。
  Number Recall §4・§8 と同形)。
- **Levels**: 4 パッド(2×2)と 6 パッド(2×3)の 2 段 × 目標長 4〜14 で 22 レベル。2 段とも
  最初から開き、段の中は順に解放する。run は長さ 3 から始まり、成功するたびに 1 ずつ伸びる。
- **Daily**: 6 パッド・目標長 10 の、今日の 1 問。
- **再生の定数**(テストで固定する): 周期 400ms 以上、消灯 120ms 以上、同時に光るのは 1 枚。
- 記録に残すのは、クリアしたレベルとデイリーの達成日だけ。聞き直しの回数は、結果の事実として
  出すだけにする(記録にしない)。間違いの回数を結果に出すかは未決(判断 2 で 1 回の run では
  常に 0 か 1 になるため — 計画の未決事項)。
- **中断と復元**(2026-10-20 の判断): run はラウンドの境目と「入力を始めたか」を保存し、列は seed から
  作り直す。入力を始める前に離れた run は、ラウンドの最初のタップの前に戻り、▶ で聞き直せる。
  **入力の途中で離れた run は、▶ を出さずに入力から(先頭から押し直して)続ける。**押した位置は
  保存しない。これで、聞き直しの条件(入力の前と失敗の後だけ)を離れても守る。
- **作らないもの**: Undo、次を光らせる Hint、ライフ、警告音、赤い明滅、振動。
- **音と見た目**: 音は `services/sound.ts` に足す WebAudio の合成音で、パッド 1 枚に 1 音の五音階。
  音を消しても、形と位置で遊べるようにする。パッドは形と位置で見分け、色は補助にとどめる。
  赤緑青黄の 4 象限の配置は使わない。
- **比較対象の製品名**は、この文書の「意図的な差分」の比較の節にだけ書く。アプリとストアの
  文言には書かない([BRAND.md](BRAND.md)「自社タイトルと比較対象の名前」)。
- **測った数値**(フィルタの通過率など)は、実装で測ってから「検証の範囲」に書く。
