# Sevens / 七並べ — rules

No. 75、`sevens`、保存 `sv.*`、Web先行公開。オーナー選定2026-11-03。
4人（あなた＋CPU3人）、52枚、ジョーカーなし。最初に全員の7を場へ出す。
♦7の持ち主から時計回り。自分の番に、同じスートの7から連続する列を1枚伸ばす。
AとKはつながらない（トンネルなし）。出せる札があってもパス可、3回まで。
4回目のパスで脱落し、残る札を全部それぞれの場所へ表に置く。飛び石になった札は
7からつながるまで列の端とはしない。終了者は飛ばし、上がり順が上位、脱落順が下位。
あなたの順位が決まった後のCPUだけの手番は計算して結果へ進む。
参照: https://www.cardgamebattle.com/cardgame/sp/sevens/rule_sevens.html （2026-11-03検索確認）。

盤面は4スート×13列。小画面では手札を大きいカードの複数段にし、出せる札と置き先を
同時に示す。札か置き先の1タップで出す。4回目のパスは脱落することを明示して確認する。
CPUは自分の札と公開された列のみで判断。難易度は1つ、手札を透視しない。
Undoなし。3ステップの図付き説明、結果・統計・共有、途中再開、同じ配札の再挑戦。
CPUの拍・時計は背景化・ダイアログ・退出中停止し、動きを減らす設定を尊重する。
保存schema v1、カード52枚の完全な分割と一意性、7、手番、パス、終了順位を検査。
