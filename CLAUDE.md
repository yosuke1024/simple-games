# Simple Games — Claude Code entry point

The shared source-of-truth entry point for this repository is:

- `docs/PROJECT_CONTEXT.md`

Read it before planning, implementing, or reviewing changes, then follow its canonical-document map for the area being changed.

Important:
- `docs/plans/`, historical issues, and comments are context, not current policy when they conflict with canonical documents.
- Do not import standard free-to-play engagement patterns by default; Simple Games intentionally rejects many of them.
- For any game change, read that game's `docs/*_RULES.md` first.
- For storage/migration, monetization, web-only behavior, public copy, or i18n, read the specific canonical documents listed in `docs/PROJECT_CONTEXT.md`.
